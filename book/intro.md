# Desarrollo de Aplicaciones Multiplataforma con Vue.js

Este libro servirá como material de apoyo a la parte de desarrollo de aplicaciones multiplataforma con **Vue.js** dentro de la asignatura de Desarrollo de Aplicaciones Avanzadas del Grado en Ingeniería Informática de la Universidad de Salamanca.

El contenido está estructurado en sesiones, cada una de las cuales aborda un tema específico relacionado con Vue y el desarrollo de aplicaciones multiplataforma. Cada sesión incluye explicaciones teóricas, ejemplos prácticos y ejercicios orientados a reforzar el aprendizaje.

Comenzaremos con los requisitos previos y una introducción a Vue para avanzar posteriormente hacia temas más complejos, como el manejo del estado, el enrutamiento, la integración con APIs y, finalmente, la construcción de aplicaciones multiplataforma.

Se recomienda seguir las sesiones en orden, ya que cada una se apoya en los conocimientos adquiridos en las anteriores. Además, conviene practicar con los ejercicios propuestos y experimentar con el código para afianzar los conceptos trabajados.

**Repositorio con ejemplos:** https://github.com/salesmendesandre/daa_vue_examples

Como material complementario y conjunto de proyectos de ejemplo, se proporcionará un repositorio en GitHub con el código fuente de las aplicaciones desarrolladas a lo largo del libro (versión Vue).

**Roadmap completo de desarrollo con Vue.js**: https://roadmap.sh/vue

Cabe destacar que este libro está en constante evolución y mejora, por lo que se anima a los lectores a contribuir con sugerencias, correcciones o nuevas ideas para enriquecer el contenido.
